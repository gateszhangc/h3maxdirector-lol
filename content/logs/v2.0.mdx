The public H3 Max Director experience now explains continuous realtime direction, persistent story context, and the path into the existing chat workspace.

## Improvements

- Director session setup with first-frame input
- 480p and 768p resolution options
- Landscape, portrait, and square formats
- Google-only sign-in
- Credit-gated access to the chat workspace

The update does not change pricing, payment integration, or generation API behavior.
